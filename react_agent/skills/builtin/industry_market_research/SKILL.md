# 行业与市场研究工作流

## 适用范围

当用户要求研究某个行业、市场、产业、赛道或板块的现状、规模、供需、价格、产业链、竞争格局、政策与技术驱动、风险或发展趋势时，使用本 Skill。简单概念解释、单一事实查询、单家公司财务分析、公司横向比较或单纯格式转换不使用本 Skill。

## 工作流程

1. 明确研究对象、地域、时间范围、用户指定维度和交付格式。信息不足时应说明实际采用的范围，不得静默混合不同地域或期间。
2. 根据任务拆分检索维度。用户未明确维度时，优先覆盖市场现状、需求、供给、价格或景气、产业链、竞争格局、政策与技术驱动、主要风险和未来展望；与目标行业无关的维度可以省略。
3. 优先查询内部知识库，并针对不同维度、时间段分别组织查询。不要用一次宽泛检索结果替代全部研究步骤，也不要为了形式完整而重复执行等价查询。
4. 区分已经发生的事实、机构预测和分析性观点。引用预测时保留预测机构、预测期间、口径和来源，不把预测值表述成已实现结果。
5. 对齐不同来源的时间、地域、统计范围、单位和指标定义。口径不一致时先解释差异，不直接合并、排名或计算。
6. 处理周报、月报和年度策略等多期材料时，应按来源时间梳理观点变化；无法确认发布时间时，不得声称某份材料是“最新”。
7. 多个来源存在分歧时，分别列明观点、证据和适用条件，再总结共识与分歧；证据不足时不得强行裁决。
8. 形成“证据—分析—结论”对应关系，清楚说明关键驱动、主要风险和当前知识库的覆盖限制。
9. 仅在用户要求文件交付时调用 Word、Excel 或 Markdown 工具；生成物中的关键事实、数字和预测同样需要保留来源与期间。

## 完成条件

- 研究范围、时间和地域边界清楚，没有把不同口径的数据直接混用。
- 用户要求的核心维度已覆盖；缺失维度明确标记为未确认或证据不足。
- 事实、预测和观点得到区分，关键数字及判断保留来源。
- 多来源共识与分歧得到如实呈现，没有把单一机构观点包装成行业共识。
- 结论能够由当前可见证据支持，并说明资料时效性与知识库覆盖限制。
- 用户要求的交付格式已经生成，或已清楚解释无法生成的原因。
