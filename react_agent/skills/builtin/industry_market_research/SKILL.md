# 行业与市场研究工作流

## 适用范围

当用户要求研究某个行业、市场、产业、赛道或板块的现状、规模、供需、价格、产业链、竞争格局、政策与技术驱动、风险或发展趋势时，使用本 Skill。简单概念解释、单一事实查询、单家公司财务分析、公司横向比较或单纯格式转换不使用本 Skill。

## 工作流程

1. 明确研究对象、地域、时间范围、用户指定维度和交付格式。信息不足时应说明实际采用的范围，不得静默混合不同地域或期间。
2. 根据任务拆分检索维度。用户未明确维度时，优先覆盖市场现状、需求、供给、价格或景气、产业链、竞争格局、政策与技术驱动、主要风险和未来展望；与目标行业无关的维度可以省略。
3. 优先查询内部知识库，并针对不同维度、时间段分别组织查询。不要用一次宽泛检索结果替代全部研究步骤，也不要为了形式完整而重复执行等价查询。
4. 按“政府、监管机构、行业协会、公司公告或投资者材料 > 权威数据库与研究机构 > 券商研报 > 主流媒体 > 转载与自媒体”选择来源。可获得一手来源时，关键数字与结论不得只引用二手转载；低权威来源只可作为检索线索或明确标注的补充观点。
5. 对行情、政策、预测、公司指引等可变信息，以系统当前时间为截止日执行最新版本检查。记录数据所属期间与来源发布日期；存在更新或修订值时，优先使用更新值并说明变化。未完成该检查时，不得使用“最新”“当前”“至今”等时效性断言。
6. 区分已经发生的事实、机构预测和分析性观点。引用预测时保留预测机构、预测期间、版本或发布日期、口径和来源，不把预测值表述成已实现结果。同一机构不同时点的预测应表述为“预测修订”，不得包装成机构间分歧。
7. 对齐不同来源的时间、地域、统计范围、单位、币种、产品规格和指标定义。口径不一致时先解释差异，不直接合并、排名或计算。
8. 对关键数字重新计算并统一表述口径，重点检查同比、环比、百分比、百分点、倍数、CAGR、单月/季度/全年及货币单位。无法从可见证据复核时，标注为来源口径，不自行推导精确数字。
9. 处理周报、月报和年度策略等多期材料时，按来源时间梳理观点变化。多个来源存在分歧时，分别列明观点、证据和适用条件，再总结共识与分歧；证据不足时不得强行裁决。
10. 将事实与因果推断分开。仅有单日价格波动、同期变化或媒体归因时，只能表述为相关性、市场解读或待验证推断；没有资金流、事件研究或多个独立来源支持时，不得写成确定因果。
11. 形成“证据—分析—结论”对应关系，清楚说明关键驱动、主要风险和当前知识库的覆盖限制。
12. 仅在用户要求文件交付时调用 Word、Excel 或 Markdown 工具；生成物中的关键事实、数字和预测同样需要保留来源、统计期间与发布日期。在调用文件工具前完成本 Skill 的成稿前质检，不得把未复核的中间结果直接写入最终文件。

## 完成条件

- 研究范围、时间和地域边界清楚，没有把不同口径的数据直接混用。
- 用户要求的核心维度已覆盖；缺失维度明确标记为未确认或证据不足。
- 可变信息已检查截止日前的最新一手版本，关键数字保留数据期间、发布日期和来源。
- 事实、预测和观点得到区分，预测版本与后续修订没有被误写为机构间分歧。
- 多来源共识与分歧得到如实呈现，没有把单一机构观点包装成行业共识。
- 倍数、比例、CAGR、单位和期间换算已复核，事实与因果推断的表述强度与证据相匹配。
- 关键结论优先引用一手来源；正文引用与来源清单一致，没有无法定位到具体来源的关键数字。
- 结论能够由当前可见证据支持，并说明资料时效性与知识库覆盖限制。
- 用户要求的交付格式已经生成，或已清楚解释无法生成的原因。
